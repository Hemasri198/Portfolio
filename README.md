# 🌐 Personal Portfolio Website

This project is a responsive personal portfolio website developed to showcase my technical skills, academic projects, and achievements as an Information Technology student.

## 🚀 Features

* Responsive design for mobile, tablet, and desktop
* Smooth scrolling navigation
* Interactive navbar with section highlighting
* Modern UI with animations and transitions
* Project showcase with clean layout
* Contact section for professional connection

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Vite (for fast development environment)

## 🎯 Purpose

The portfolio serves as a professional platform to present my work, demonstrate front-end development skills, and create an online presence for internships and job opportunities.

## 📂 Project Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Hemasri198/Portfolio.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open in browser:

   ```
   http://localhost:5173
   ```
6. Live Demo:
   ```
   https://portfolio-eta-six-95.vercel.app/
   ```
